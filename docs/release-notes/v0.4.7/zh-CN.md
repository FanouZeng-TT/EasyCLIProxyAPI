## Codex 独立 apply_patch 工具

- 配套交付 **CPA GUI 0.4.7 + CPA 内核 8.0.40**，安装包内含匹配内核。
- 内核新增插件 `executor_apply_patch` 能力声明及 `executor_apply_patch_models` 模型前缀范围；仅当模型的所有候选执行器均支持时，才公开 `apply_patch_tool_type: freeform`。
- GUI 将内核报告的能力同步到受管的 Codex 模型目录，使支持该能力的 Codex 客户端能够注册独立 `apply_patch` 工具，显示文件编辑操作；无需修改 Codex 客户端源码。
- 新安装及缺少该配置的已有安装默认开启能力公开；用户明确设置的关闭状态会保留。

## 适用范围与插件交付

- 本次发布的是内核能力传递与 GUI 配置支持。字节模型插件仍通过内部商店单独发布，本安装包不包含它的新版本。
- 旧插件未声明能力时保持原行为。LLMBox、TRAE 的具体转换支持以配套插件实际声明及实现为准，升级本安装包不会让未声明的模型自动获得该能力。
- 自动目录同步仅面向受管的 Codex 配置。公共 `/v1/models` 对已确认支持的模型增加可选能力字段；其他客户端的请求与响应协议保持原行为，不会被自动注入工具。

## 验证范围

- GUI 配置与目录的 145 项回归测试及前端类型检查通过；内核能力相关包测试、并发回归与全量静态检查通过。
- 内核全量测试存在 Home 集群心跳超时测试失败，已在未修改基线复现；首次全量运行还出现一项 Home 客户端关闭等待超时，独立复测通过。本次不宣称内核全量测试通过。
