## Codex 模型上下文配置

- “模型列表设置”和“更新配置”使用一致的上下文容量规则。
- 获取到上游真实最大容量时，最终上下文上限取 **350K、上游硬上限、用户配置值**三者的最小值。
- 获取不到上游真实最大容量时，保留用户配置，不施加 350K 限制；可以配置 500K、1M 等容量，但不保证上游一定支持。
- 用户未配置时默认使用 **250K Token**；已知上游容量小于 250K 时，进一步降低到上游容量。
- 保留模型列表中的自定义设置；已有 Codex 全局上下文配置同步到当前模型的有效容量，自动压缩阈值不会超过最终上下文上限。

## 配套插件说明

- 此 GitHub Release 发布的是 **CPA GUI 0.4.6**，不包含字节模型插件的新版本。
- 旧版字节模型插件会把未知容量报告成 350K，GUI 无法判断它是默认值还是真实容量。因此，“未知容量保留大窗口配置”需要配套安装能保留未知容量状态的新版插件；插件仍通过内部商店单独发布。
- 本次不改变单次回复的输出 Token 上限，也不新增图片或视频生成功能。
